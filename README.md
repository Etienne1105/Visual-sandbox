# Visual Sandbox

Projet de test pour le skill **Visual Excellence**. Ce repository contient un site web multi-pages avec des composants UI volontairement imparfaits, concu pour servir de terrain d'experimentation.

## Structure

```
Visual-sandbox/
├── index.html              # Page d'accueil (hero, features, composants, temoignages)
├── pages/
│   ├── dashboard.html      # Dashboard (stats, graphiques, tableaux)
│   ├── forms.html          # Formulaires (login, inscription, contact, preferences)
│   └── gallery.html        # Galerie (grilles, cartes produit, modale)
├── css/
│   └── style.css           # Feuille de styles principale
├── js/
│   └── main.js             # JavaScript (onglets, modales, validation)
└── assets/                 # Repertoire pour les ressources (images, icones)
```

## Composants disponibles

- **Navigation** : barre de navigation responsive avec menu mobile
- **Hero** : section d'en-tete avec CTA
- **Cartes** : feature cards, stat cards, product cards, testimonial cards
- **Tableaux** : table de donnees avec pagination
- **Formulaires** : login, inscription, contact, preferences avec toggles
- **Alertes** : succes, warning, erreur, info
- **Badges** : differents etats et couleurs
- **Barres de progression** : avec variantes de couleur
- **Onglets** : navigation par onglets
- **Boutons** : primary, secondary, success, danger, outline, ghost
- **Galerie** : grille masonry avec overlay et modale
- **Graphiques CSS** : bar chart et donut chart
- **Upload** : zone de drag & drop

## Utilisation

Ouvrir `index.html` dans un navigateur pour voir le site. Aucun build n'est necessaire.
